# The Faction List According to Games Workshop

This is it--The actual faction list, from Games Workshop itself. I am basing it off their website, how they categorize the factions themselves.

## Counting Lenses

The same faction space produces different totals depending on which source and
which product boundary is being counted. These counts should not be mixed in a
single table without naming the lens being used.

| Lens                            | Count | Meaning                                                                                      |
| ------------------------------- | ----: | -------------------------------------------------------------------------------------------- |
| GW Online Store taxonomy        |    38 | Store navigation factions/categories exactly as GW presents them                             |
| BSData raw `.cat` files         |    46 | All catalog files in `/Users/mikeearley/code/wh40k-10e`, including libraries/helper catalogs |
| BSData non-library `.cat` files |    38 | Top-level playable-ish catalogs, but includes Ynnari and Unaligned Forces                    |
| New Recruit-style faction list  |    36 | BSData-derived list excluding Ynnari and Unaligned Forces as app factions                    |
| 40karmy target faction list     |    34 | New Recruit-style 36 minus Adeptus Titanicus and Titanicus Traitoris                         |

## GW vs BSData Differences

GW's 38-count store taxonomy and BSData's 38 non-library catalog files land on
the same number by coincidence. They are not the same set.

| Item                | GW Store                   | BSData Catalog      | 40karmy Target | Notes                                    |
| ------------------- | -------------------------- | ------------------- | -------------- | ---------------------------------------- |
| Iron Warriors       | Yes                        | No separate catalog | No             | Chaos Space Marines sub-faction/category |
| Red Corsairs        | Yes                        | No separate catalog | No             | Chaos Space Marines sub-faction/category |
| Ynnari              | No top-level store faction | Yes                 | No, for now    | Aeldari army construction variant        |
| Unaligned Forces    | No standard army faction   | Yes                 | No             | Utility/legacy/terrain-style catalog     |
| Adeptus Titanicus   | Yes                        | Yes                 | No, for now    | Separate game-system-ish catalog         |
| Titanicus Traitoris | Yes                        | Yes                 | No, for now    | Separate game-system-ish catalog         |

## New Recruit

New Recruit lands at 36 factions, but that number has to be read relative to the
source being compared:

- Compared with the GW Online Store 38, New Recruit does not treat Iron Warriors
  or Red Corsairs as separate app factions.
- Compared with BSData's 38 non-library catalogs, New Recruit does not expose
  Ynnari or Unaligned Forces as app factions.

Those are two different 38-count inputs that converge on the same 36-count app
list.

### Imperium Count- 8 Factions

The Imperium mirrors the above list, except they move Grey Knights from Space Marines to Imperium.

### Space Marines Count - 12 Factions

The Space Marines list on New Recruit is the same as above, except they lose Grey Knights to the Imperium list.

### Chaos Count - 8 Factions

Chaos sees the biggest change, as they lose Iron Warriors and Red Corsairs as separate factions, which is understandable--they are, essentially, Chaos Space Marines detachment factions. One could argue that they are identical to White Scars, Salamanders, Raven Guard, etc.--but whatever.
